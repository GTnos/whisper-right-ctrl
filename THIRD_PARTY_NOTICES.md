# Third-party software

Whisper Right Ctrl installs third-party Python packages from their official package distributions. Those packages are not relicensed by this project. Review their current upstream licenses before redistributing a binary bundle:

- [faster-whisper](https://github.com/SYSTRAN/faster-whisper)
- [CTranslate2](https://github.com/OpenNMT/CTranslate2)
- [OpenCC](https://github.com/BYVoid/OpenCC)
- [python-sounddevice](https://github.com/spatialaudio/python-sounddevice)
- [pynput](https://github.com/moses-palmer/pynput)
- [pyperclip](https://github.com/asweigart/pyperclip)
- [pystray](https://github.com/moses-palmer/pystray)
- [Pillow](https://github.com/python-pillow/Pillow)
- NVIDIA CUDA and cuDNN Python packages

The Whisper-compatible model is downloaded separately on first launch from its model host. The model is not included in this repository or release ZIP and remains subject to the terms published with that model.
